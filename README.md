# Portfólio — Guilherme Dias

Site pessoal de portfólio, publicado em **[gdias-dev.github.io/portifolio-gdias](https://gdias-dev.github.io/portifolio-gdias/)**.

Página única, sem dependências de build: todo o CSS e o JavaScript estão embutidos no `index.html`.

## Características

- **Tema escuro** com destaques em azul e ciano
- **Bilíngue** — alternância entre português e inglês por botão, sem recarregar a página
- **Responsivo**, de celular a desktop
- **Animação de entrada** das seções via `IntersectionObserver`
- **Modal de contato** com e-mail, WhatsApp, LinkedIn e GitHub

## Conteúdo

Apresenta os sistemas em produção que desenvolvi para a Nova Varonil — painel comercial com mapa de clientes, gestão de estoque, orçamento automático de lentes e controle de ponto — além do agente de IA Nina e de projetos pessoais.

## Stack

HTML5, CSS3 e JavaScript sem frameworks. Fontes via Google Fonts. Hospedado no GitHub Pages.

## Como rodar localmente

Basta abrir o `index.html` no navegador. Não há dependências nem etapa de build.
